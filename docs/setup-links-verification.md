# Optional setup handoff browser acceptance (#395)

Run only the isolated setup-links suite:

```sh
python3 e2e/run-setup-links.py /tmp/mycfc-setup-links-evidence
```

An optional `--app-source /path/to/frozen/source` compiles another checkout while reading these new tests from the current checkout. Docker, Go and npm are prerequisites. Evidence must be a new directory outside source checkouts and is created mode 0700. Existing group, season and week suites are left unchanged and are not rerun by this command.

The runner owns one PostgreSQL 16.9 container, loopback application/attacker ports and the complete fresh baseline/migration ledger. PostgreSQL uses Europe/Lisbon. Browser dependencies use the existing exact lockfile; pinned Playwright 1.63.0 runs as the caller's UID/GID with read-only sources and dependencies, one worker and zero retries. Caller application/cloud secrets are not inherited. Both success and failure stop owned servers, remove only owned containers/volumes and record port cleanup.

The fixture is wholly synthetic: adult actors, one registered season with explicit synthetic bounds, programme and team-only grants, ready/empty groups, registered weeks, an empty selected day, and name-only classification search subjects. It includes a scoped anchored person for individual no-matching-category guidance and an unanchored person whose eligibility must remain masked. This is fixture provisioning, not the complete #404 coach setup or a canonical club calendar.

Coverage follows actual server-rendered routes and native forms: ready coach goes directly to the exact week/day; optional help separates missing current season, missing programme definitions, no available name results and missing programme authority; team-only access does not become programme configuration permission. Existing definitions support cancel/error/save returns, and classification search/result/change-person/pagination carry the typed origin. Assignment preview/confirmation and scoped selection correction return explicitly to the originating week/day without automatically adding group membership or publishing instructions.

All missing-current-season handoffs deliberately select the same already-registered season used by the fixture weeks. Group handoff returns directly to the exact planner; classification/definitions handoffs return first to the fixed existing task and then its explicit group-return action. Stored season identity/dates, planning rows and group placements are compared before and after. No new season is invented to satisfy a test, and historical weeks are not reclassified into another season.

Origin security cases distinguish separate contracts. Unauthorized/revoked origins must reject before rendering otherwise searchable subject data. Invalid cross-group week/day values must safely canonicalize to the authorized group rather than gain authority. Fresh signed assignment/correction tokens transplanted to a different authorized origin must reject without writes. Retained scoped feedback for an already-authorized person is not treated as a profile permission. Existing origin-free tasks remain usable.

A file handshake revokes only the fixture origin-programme grant after a real classification form has rendered, leaving other programme authority intact to verify the origin check independently. A separate loopback origin serves only one fixed attacker form and checks real authenticated Origin/Fetch Metadata denial on the raw definitions action. No mock application pages, forged authentication, synthetic signed tokens or clock changes are used. The shared fifteen-minute token TTL is unchanged and its natural-expiry wait is not repeated here.

Actual route axe checks fail on serious/critical findings. Keyboard focus, native no-JavaScript paths, 320px/desktop layout, privacy headers, masked individual eligibility and absence of DOB/email/profile expansion are checked separately. Screenshots support visual review; manual screen-reader, real browser zoom, forced colours/reduced motion, coach observation and full #391/#404 acceptance remain unverified. No merge, deployment, production mutation or private-plan import is part of this work.
