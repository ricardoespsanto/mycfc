## Implemented behavior

The selected week, day or session offers a native copy task. Configured session,
segment and block routines use the existing scoped library. Source and target
access, configured season, week, mapping dates/clocks and copied content are
reviewed before explicit confirmation. The result is an independent editable
draft with provenance; it does not copy roster, publications, prescriptions,
outcomes or personal variations. Returning to the selected destination does not
publish. Contextual Adapt opens the existing variation form and conflict rules.

Source and target selectors are fixed after signed review; changed facts require
explicit review or reload. Proof replay returns the same retained destinations,
without allocating another graph. Aggregate writes preserve native ordering,
recovery and represented gym/water instructions. Direct copies preserve nullable
native session metadata; routines reproduce their stored snapshot facts and do
not invent legacy fields absent from that snapshot.
