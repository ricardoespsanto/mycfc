# Mixed-schedule publication: local verification

This completes the local native copy/edit/review/publish increment under #401
and advances #403. It is not full #391 acceptance or release authority. Dated
placements/withdrawal, craft guidance, both real coach plans and human acceptance
remain separate required integrations.

The existing publication engine supports INTERVAL, START_ONLY, DAY and BAND.
Partial schedules retain native microseconds, explicit missing endpoints and
full week metadata in v2; INTERVAL v1 bytes remain unchanged. The original
admitted transaction, actor/guardian/source checks and known/unknown commit
protocol remain. PostgreSQL measures each v2 artifact before review and writes;
the exact 200000-byte boundary accepts and 200001 refuses the whole operation.
A verified shared-slice defect was fixed by decoding each recipient into a fresh
session before resolving personal variations.

Review now shows one canonical athlete/workout instruction at a time. Native
selection retains the original complete signed review and never publishes or
re-signs it. Changed audience/content/header or expiry refuses inspection and
confirmation, hides stale instructions and preserves the user's own summary and
proof. The existing renderer shows personal versus common instructions before
confirmation; it is not a second prescription model.
